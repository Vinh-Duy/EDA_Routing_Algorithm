# Multi-terminal experiment files

`layouts/` contains four fixed cases; `baseline_layouts/` contains deterministic
S/T-only projections generated by `run_multiterminal.py` with P cells replaced by
empty cells. The projected controls have fewer terminals than the tree cases and
must not be used for an equal-connectivity quality claim.

Use [the final recorded comparison](experiment_20261026_final/RESULTS.md) with its
raw CSVs and metadata as the canonical experiment. It contains 120 checked
observations, 24 excluded warm-ups, source/input/executable hashes, a fixed
shuffle seed, per-net failure records, and termination reasons. The prior router
compatibility result is in [COMPATIBILITY.md](COMPATIBILITY.md).

Two earlier experiment folders are retained as audit artifacts. They were recorded
while the comparison table and its relative link were being refined. Their raw
routing observations were independently checked at execution time, but their
metadata records an earlier revision of the report-generation script; only the
final folder matches all current script hashes. The recorded routing inputs,
quality metrics, and raw samples were not rewritten.
